# ApexGrid

Sistema de gestión empresarial de escritorio para PyMEs y profesionales independientes.

## 📋 Descripción

ApexGrid es una aplicación de escritorio desarrollada en Java que permite gestionar clientes, proyectos y presupuestos de manera eficiente. Diseñada específicamente para pequeñas y medianas empresas que buscan una alternativa accesible a los sistemas ERP/CRM tradicionales.

## ✨ Características principales
- 👥 Gestión de clientes con información detallada
- 📊 Administración de proyectos con seguimiento de estado
- 💰 Control de presupuestos y estados
- 🔐 Sistema de autenticación de usuarios
- 💾 Base de datos SQLite embebida
- 🖥️ Interfaz moderna con JavaFX

## 🚀 Tecnologías utilizadas
- **Lenguaje**: Java 11+
- **Interfaz**: JavaFX
- **Base de datos**: SQLite
- **Gestión de dependencias**: Maven
- **Empaquetado**: Launch4j
- **IDE**: IntelliJ IDEA

## 🛠️ Desarrollo

### Compilar desde el código fuente
```bash
# Clonar el repositorio
git clone https://github.com/tuusuario/ApexGrid.git

# Navegar al directorio
cd ApexGrid

# Compilar con Maven
mvn clean install

# Ejecutar la aplicación
java -jar target/ApexGrid-1.0.jar
```
